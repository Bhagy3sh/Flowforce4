# 🌊 Flowforce 4 Website

A modern, responsive website for Flowforce 4 built with React, Vite, Framer Motion, Swiper, and React Icons.

## 🛠️ Tech Stack

- React 19.2.0
- Vite 4.5.0
- Framer Motion 12.31.0
- Swiper 12.1.0
- React Icons 5.5.0

## 📦 Installation

```bash
npm install
```

## 🏃 Running the Project

```bash
npm run dev
```

The site will be available at `http://localhost:5173/`
